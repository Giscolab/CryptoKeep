CryptoKeep chiffre vos entrées sur votre appareil. L'application Windows utilise Tauri et WebView2 ; la version web fonctionne avec le serveur local fourni.

Télécharger la préversion Windows x64

Version 0.1.0 · Installateur non signé · Contrôles complémentaires à mener

Les fonctions disponibles

Un coffre chiffré

Création, déverrouillage, gestion des entrées et verrouillage automatique configurable. AES-GCM 256 bits et dérivation PBKDF2 via Web Crypto.

Des sauvegardes choisies

Export chiffré au format .vault, import .vault et CSV. Les exports CSV et JSON sont en clair et demandent une confirmation.

Des outils locaux

Générateur, recherche, tris, thèmes et analyse de robustesse et de réutilisation. Pas de synchronisation ni de compte distant.

Aucune donnée préchargée

L'installateur ne contient aucun coffre, mot de passe ni compte de démonstration. Sur un profil vierge, vous créez votre coffre avec votre propre mot de passe maître.

Le coffre et sa copie secondaire vivent dans le même profil local. Conservez un export .vault séparé : la suppression du profil ou une panne peut entraîner la perte des deux copies.

Le frontend desktop bloque les requêtes distantes. Le système et WebView2 ont leur propre comportement réseau. Dans la version web, la consultation HIBP est facultative et désactivée par défaut.

Une documentation fondée sur le code

Cette première livraison est une préversion, sans certification de sécurité annoncée. La 2FA, WebAuthn et le remplissage automatique ne sont pas implémentés.
